# 操作解説動画 要件定義書

作成日: 2026-07-29
ステータス: 要件確定（ユーザーヒアリング済み）

## 1. 背景とゴール

[ヘルプページ](https://youkiti.github.io/tiab-review-plugin/help.html) の内容をもとに、
TiAb Review Plugin の操作解説動画を制作する。

### ゴール

1. **1本の動画を YouTube にアップロードし、各操作ごとに頭出し（チャプター）できる状態**にする
2. **機能追加に応じて随時更新が可能な状態**にする（該当セクションのみ再収録して再構成できる）

## 2. 確定した要件（ヒアリング結果）

| 項目 | 決定内容 | 理由・補足 |
| --- | --- | --- |
| 制作方式 | **Playwright による自動収録** | 操作をシーンスクリプトとしてリポジトリ管理。機能追加時はスクリプト修正+再実行で該当シーンだけ再収録できる |
| ナレーション | **AI 音声（TTS）** | 原稿（テキスト）をリポジトリ管理し、更新時は該当部分のみ再生成 |
| 言語 | **日本語ナレーション + 英語字幕** | 動画は日本語 1 本。英語は YouTube の字幕トラック（.srt）で対応 |
| カバー範囲 | **全機能**（基本フロー / ML・AI スクリーニング / フルテキスト / 共有・チーム運用・設定） | ヘルプページの全セクションに対応 |
| デモ環境 | **デモ専用 Google アカウント + デモ用プロジェクト** | 個人情報の映り込みを防ぎ、常に同じ状態から再収録できる。文献データは `sample/pubmed-srws-psgad-set.nbib` を使用 |
| 動画の長さ | **標準 10〜15 分** | 各機能 1〜2 分。詳細はヘルプページに誘導 |
| 更新時の公開運用 | **新規公開 + リンク自動更新** | YouTube は動画本体の差し替えが不可のため、更新のたびに新規動画を公開。`docs/help.html` 等のリンクとチャプター情報を同じ PR で更新し、旧版は非公開化。ユーザーは常にヘルプページ経由で最新版に到達する |
| アップロード方法 | **手動アップロード** | パイプラインは「動画ファイル + チャプター付き説明文 + サムネイル」までを生成し、アップロードと公開設定は手動で実施 |

## 3. チャプター構成（案）

ヘルプページのセクション構成に対応させる。各チャプター = 1 シーンスクリプト = 1 ナレーション原稿。

| # | チャプター | 目安時間 | ヘルプページ対応セクション |
| --- | --- | --- | --- |
| 1 | イントロ（ツール概要） | 0:30 | 冒頭 |
| 2 | ログインとプロジェクト作成・接続 | 1:30 | ログイン画面 |
| 3 | TiAb スクリーニング（手動タブ） | 2:00 | TiAb スクリーニング / ツールバー機能 |
| 4 | キーボードショートカット | 0:45 | キーボードショートカット |
| 5 | ML スクリーニング | 1:30 | ML スクリーニング（利用条件・使い方） |
| 6 | AI スクリーニング支援 | 1:30 | AI スクリーニング支援（API キー設定含む） |
| 7 | フルテキストスクリーニング | 2:00 | フルテキストスクリーニング（3 つのサブビュー） |
| 8 | 共有とチーム運用 | 1:30 | 共有ダイアログ / チーム運用 |
| 9 | Web 版の紹介 | 0:45 | Web 版（インストール不要） |
| 10 | 設定オプション | 1:00 | 設定 |
| 11 | アウトロ（ヘルプページ・問い合わせ先の案内） | 0:30 | — |

合計目安: 約 13〜14 分

## 4. 制作パイプラインの構成（設計方針）

```
video/
├── REQUIREMENTS.md          # 本書
├── scenes/                  # Playwright シーンスクリプト（チャプターごとに1ファイル）
│   ├── 01-intro.ts
│   ├── 02-login-project.ts
│   └── ...
├── narration/               # ナレーション原稿（チャプターごとに1ファイル、日本語）
│   ├── 01-intro.md
│   └── ...
├── subtitles/               # 英語字幕ソース（原稿から生成・レビューして確定）
├── assets/                  # サムネイル素材・静止画（ログイン画面説明用など）
├── build/                   # 生成物（git 管理外）: シーン動画 / TTS 音声 / 最終 mp4 / chapters.txt / .srt
└── scripts/                 # ビルドスクリプト（収録→TTS→合成→チャプター生成）
```

### 処理フロー

1. **収録**: Playwright（持続コンテキスト + `--load-extension`）で拡張を読み込み、シーンごとに操作を実行して録画。
   サイドパネルは `chrome-extension://<id>/sidepanel.html` を直接ページとして開いて収録する方式を第一候補とする
2. **音声生成**: ナレーション原稿から TTS で音声ファイルを生成（チャプター単位）
3. **合成**: ffmpeg でシーン動画 + 音声を結合し、1 本の mp4 に連結。
   各シーンの実測尺から **YouTube 説明欄用チャプタータイムスタンプ（chapters.txt）を自動生成**
4. **字幕**: ナレーション原稿から英語 .srt を生成（タイムスタンプはシーン尺から算出）
5. **アップロード（手動）**: mp4 / chapters.txt 入り説明文 / サムネイル / .srt を YouTube Studio から手動アップロード
6. **リンク更新**: 新しい動画 URL とチャプター情報を `docs/help.html`（および必要箇所）に反映する PR を作成。旧動画は非公開化

### 更新ワークフロー（機能追加時）

1. 該当シーンスクリプトとナレーション原稿だけを修正
2. パイプラインを再実行（変更のないシーンは既存収録を再利用可能な設計とする）
3. 新規動画としてアップロードし、リンク更新 PR を出す

## 5. 未決事項（実装フェーズで決定）

| 項目 | 選択肢 | 備考 |
| --- | --- | --- |
| TTS エンジン | VOICEVOX（無料・ローカル・クレジット表記で商用可）/ Google Cloud TTS / OpenAI TTS | 品質・コスト・CI での再現性を比較して決定 |
| 解像度・フレームレート | 1920x1080 / 30fps を基本線 | 文字の可読性を実機で確認して確定 |
| デモ専用アカウントの認証情報管理 | ローカル `.env`（git 管理外） | AGENTS.md の機密情報保護ルールに従う。CI では収録しない前提 |
| ML スクリーニングの利用条件の再現 | デモプロジェクトに十分な評価済み件数を事前投入 | シードデータ投入スクリプトで再現可能にする |
| サムネイル | 静的テンプレート + バージョン表記 | assets/ にテンプレートを置き半自動生成 |

## 6. 受け入れ基準

- [ ] YouTube 上の 1 本の動画で、説明欄のチャプターから各操作に頭出しできる
- [ ] 英語字幕トラックが表示できる
- [ ] `docs/help.html` から最新の動画に到達できる
- [ ] シーンスクリプト・原稿の修正 + パイプライン再実行だけで更新版動画一式（mp4 / chapters.txt / .srt）が生成できる
- [ ] 動画・原稿・収録スクリプトがすべてリポジトリでバージョン管理されている（生成物を除く）
