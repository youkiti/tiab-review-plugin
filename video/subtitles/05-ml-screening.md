## cue 01
The "ML" tab lets you screen with machine-learning-based active learning. It is available for projects with 1,000 or more references.

## cue 02
The first time you open it, a dialog asks you to review the stopping rule — the criteria for deciding when it is safe to stop screening. Confirm it to start.

## cue 03
Usage is the same as the Manual tab: judge each record as Include or Exclude. Once there is at least one Include and one Exclude, model training starts automatically.

## cue 04
The model retrains in the background with every new decision, so likely-relevant records surface first. There is no need to pause screening while it learns.

## cue 05
When the stopping rule is met, the screen tells you — so you can decide how far to read based on data.
