🔬 TiAb Review Plugin

Systematic Review のタイトル・抄録スクリーニングを効率化する Chrome 拡張機能 A Chrome extension to streamline title and abstract screening for Systematic Reviews
GitHub 機能を見る / Features

主な機能 Key Features

📊

Google Sheets 連携 Google Sheets Integration

スクリーニング結果を Google Sheets に自動保存。チームでのリアルタイム共有が可能です。 Auto-save screening results to Google Sheets. Real-time sharing with your team.

📁

RIS/NBIB インポート RIS/NBIB Import

PubMed、CENTRAL などから出力した文献リストを簡単にインポートできます。 Easily import reference lists exported from PubMed, CENTRAL, and more.

🏷️

効率的なスクリーニング Efficient Screening

Include/Exclude をワンクリックで判定。キーボードショートカットにも対応。 One-click Include/Exclude decisions. Keyboard shortcuts supported.

👥

チーム共有 Team Collaboration

共同研究者とスプレッドシートを共有して、複数人でのスクリーニングが可能。 Share spreadsheets with collaborators for multi-reviewer screening.

📤

CSV エクスポート CSV Export

スクリーニング結果を CSV 形式でエクスポート。他のツールとの連携も簡単。 Export screening results as CSV. Easy integration with other tools.

🔒

セキュア Secure

データはすべてあなたの Google Drive に保存。第三者サーバーへの送信はありません。 All data stored in your Google Drive. No third-party server transmission.

使い方 How to Use

1

拡張機能をインストール Install the Extension

Chrome ウェブストアから TiAb Review Plugin をインストールします。 Install TiAb Review Plugin from the Chrome Web Store.

2

Google アカウントでログイン Sign in with Google

Google Sheets / Drive へのアクセスを許可します。 Grant access to Google Sheets / Drive.

3

文献リストをインポート Import References

RIS または NBIB 形式のファイルをアップロードします。 Upload files in RIS or NBIB format.

4

スクリーニング開始 Start Screening

タイトルと抄録を確認し、Include/Exclude を判定していきます。 Review titles and abstracts, then decide Include/Exclude.
