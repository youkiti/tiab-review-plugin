🔬 TiAb Review Plugin

Systematic Review のタイトル・抄録スクリーニングを効率化する Chrome 拡張機能

GitHub で見る 機能を見る

主な機能

📊

Google Sheets 連携

スクリーニング結果を Google Sheets に自動保存。チームでのリアルタイム共有が可能です。

📁

RIS/NBIB インポート

PubMed、CENTRAL などから出力した文献リストを簡単にインポートできます。

🏷️

効率的なスクリーニング

Include/Exclude をワンクリックで判定。キーボードショートカットにも対応。

👥

チーム共有

共同研究者とスプレッドシートを共有して、複数人でのスクリーニングが可能。

📤

CSV エクスポート

スクリーニング結果を CSV 形式でエクスポート。他のツールとの連携も簡単。

🔒

セキュア

データはすべてあなたの Google Drive に保存。第三者サーバーへの送信はありません。

使い方

1

拡張機能をインストール

Chrome ウェブストアから TiAb Review Plugin をインストールします。

2

Google アカウントでログイン

Google Sheets / Drive へのアクセスを許可します。

3

文献リストをインポート

RIS または NBIB 形式のファイルをアップロードします。

4

スクリーニング開始

タイトルと抄録を確認し、Include/Exclude を判定していきます。
