🔬 TiAb Review Plugin

利用規約

最終更新日: 2025年12月27日

第1条（適用）

本利用規約（以下「本規約」）は、TiAb Review Plugin（以下「本サービス」）の利用条件を定めるものです。ユーザーは本サービスをインストールまたは使用することにより、本規約に同意したものとみなされます。

第2条（サービスの概要）

  1. 本サービスは、Systematic Review のタイトル・抄録スクリーニングを効率化するための Chrome 拡張機能です。
  2. 本サービスは、Google Sheets API および Google Drive API を利用してデータの保存・管理を行います。
  3. 本サービスは無料で提供され、研究・学術目的での利用を想定しています。

第3条（利用登録）

  1. 本サービスの利用には Google アカウントが必要です。
  2. ユーザーは、Google アカウントを通じて本サービスに OAuth 認証を許可することで、サービスを利用できます。

第4条（禁止事項）

ユーザーは、本サービスの利用にあたり、以下の行為を行ってはなりません。

  1. 法令または公序良俗に違反する行為
  2. 本サービスの運営を妨害する行為
  3. 本サービスのリバースエンジニアリング、逆コンパイル、または逆アセンブル
  4. 本サービスを悪用した不正アクセスやセキュリティ攻撃
  5. 第三者になりすます行為
  6. その他、開発者が不適切と判断する行為

第5条（データの取り扱い）

  1. 本サービスは、ユーザーの Google アカウント情報（メールアドレス）および Google Sheets/Drive のデータにアクセスする許可を要求します。
  2. これらのデータは、スクリーニング作業の遂行およびデータの保存・共有のためにのみ使用されます。
  3. ユーザーのデータは、ユーザー自身の Google Drive に保存され、開発者のサーバーに送信・保存されることはありません。
  4. 詳細については、プライバシーポリシーをご確認ください。
