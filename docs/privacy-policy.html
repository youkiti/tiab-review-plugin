🔬 TiAb Review Plugin

プライバシーポリシー / Privacy Policy

最終更新日: 2026年10月20日 / Last Updated: October 20, 2026

1. はじめに / Introduction

TiAb Review Plugin（以下「本サービス」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めています。本プライバシーポリシーは、本サービスが収集する情報とその利用方法について説明します。

TiAb Review Plugin ("the Service") respects user privacy and is committed to protecting personal information. This Privacy Policy explains what information we collect and how we use it.

2. 収集する情報 / Information We Collect

本サービスは、以下の情報にアクセスする許可を要求します：

The Service requests permission to access the following information:

  • Google アカウント情報 / Google Account Information：: メールアドレス（ユーザー識別のため） / Email address (for user identification)
  • Google Sheets データ / Google Sheets Data：: ユーザーが本サービスに接続したスプレッドシート（本サービス内で新規作成したもの、およびユーザーが Google ピッカーで明示的に選択したもの）に対する、スクリーニングデータの読み取り・書き込み / Reading and writing screening data in spreadsheets that the user connects to the Service — including spreadsheets newly created within the Service and spreadsheets explicitly selected by the user with Google Picker
  • Google Drive ファイル / Google Drive Files：: 本サービスがユーザーの Google Drive 内に作成したファイル・フォルダ（プロジェクト用フォルダ、取得した全文PDF等）へのアクセス / Access to files and folders that the Service creates in the user's Google Drive (e.g., project folders and retrieved full-text PDFs)
  • AI（LLM）判定機能（任意） / AI (LLM) Screening Feature (Optional)：: ユーザーが明示的に実行した場合に、ユーザーが選んだ AI プロバイダ（Google Gemini、OpenRouter、OpenAI、Anthropic、TypeSafe、ローカル LLM のいずれか）の API へ、文献のタイトル・抄録と判定基準・プロンプトを送信します。ローカル LLM はこの PC のループバックアドレスだけに接続し、クラウド AI に送りません。URL とモデル一覧は端末内に暗号化せず保存し、API キーは使いません。レビュー情報と判定の保存には引き続き Google Sheets を使います。フルテキストの AI 判定では、PDF ファイル全体を Gemini API に送信します。 / When explicitly run by the user, the Service sends reference titles and abstracts, together with the review criteria and prompt, to the API of the AI provider the user selected (Google Gemini, OpenRouter, OpenAI, Anthropic, TypeSafe, or Local LLM). Local LLM connects only to this computer's loopback addresses, without sending data to cloud AI. Its URL and model list are stored unencrypted on the device; no API key is used. Review data and decisions still use Google Sheets for storage. For full-text AI screening, the entire PDF file is sent to the Gemini API.
  • 全文 PDF の検索・レジストリ連携（任意） / Full-Text PDF Search and Registry Linkage (Optional)：: フルテキストの取得やレジストリ連携を実行した場合に、文献の DOI・PMID・試験登録番号などの識別子を、オープンアクセスの検索サービスや試験登録サイトへ送信します。Unpaywall と OpenAlex には、各サービスの利用規約に従い、ログイン中の Google アカウントのメールアドレスも送信します。 / When full-text retrieval or registry linkage is run, identifiers such as DOI, PMID, and trial registration numbers are sent to open-access search services and trial registries. For Unpaywall and OpenAlex, the email address of the signed-in Google account is also sent, as those services' terms require.
  • 拡張機能のローカル保存データ / Extension Local Storage：: 設定（スプレッドシートID、UI設定等）、オフライン同期用の判定キュー、（任意）AI プロバイダの API キーをユーザー端末内に保存します。 / We store settings (spreadsheet ID, UI preferences, etc.), an offline decision queue for synchronization, and (optionally) AI provider API keys on the user's device.

3. 情報の利用目的 / How We Use Information

収集した情報は、以下の目的でのみ使用されます：

The information collected is used only for the following purposes:

  • スクリーニングデータの保存・表示 / Saving and displaying screening data
  • ユーザーの識別とアクセス管理 / User identification and access management
  • スプレッドシートの共有機能の提供 / Providing spreadsheet sharing functionality
  • （任意）AI（LLM）による判定支援 / (Optional) Decision support via AI (LLM)
  • （任意）オープンアクセスの全文 PDF の検索 / (Optional) Searching for open-access full-text PDFs

4. データの保存場所 / Data Storage

重要：本サービスは、ユーザーのデータを開発者のサーバーに送信・保存しません。

Important: The Service does not send or store user data on the developer's servers.

すべてのスクリーニングデータは、ユーザー自身の Google Drive 内の Google Sheets に保存されます。データの管理権限はユーザー自身にあります。

All screening data is stored in Google Sheets within the user's own Google Drive. Users have full control over their data.

また、本拡張機能の設定やオフライン同期用の判定キューは、ユーザー端末内（Chrome 拡張機能のストレージ / IndexedDB）に保存される場合があります。

In addition, the extension's settings and offline decision queue may be stored on the user's device (Chrome extension storage / IndexedDB).

AI プロバイダの API キーは、ユーザーが「保存」を選択した場合に限り、ユーザー端末内に保存されます（開発者のサーバーには送信・保存しません）。

AI provider API keys are stored only on the user's device if the user chooses to save them (we do not send or store them on developer servers).

開発者は、ユーザーが本サービスに取り込んだ文献情報・判定・PDF の内容について権利を主張せず、AI モデルの学習を含むいかなる目的にも利用しません。

The developer claims no rights to the references, decisions, or PDF content that users bring into the Service, and does not use them for any purpose, including training AI models.

5. 情報の第三者提供 / Third-Party Disclosure

本サービスは、ユーザーの個人情報を第三者に販売、貸与、または不必要に共有しません。

The Service does not sell, rent, or unnecessarily share user personal information with third parties.

ただし、本サービスの提供に必要な範囲で、ユーザーの操作に応じて以下の第三者サービスへデータを送信する場合があります：

However, to provide the Service, we may send data to the following third-party services based on user actions:

  • Google Sheets API / Google Drive API / Google Picker API（スプレッドシートの読み書き、作成・選択のため） / Google Sheets API / Google Drive API / Google Picker API (to read/write, create, and select spreadsheets)
  • AI プロバイダ（ユーザーが選んだもの）※任意機能（判定支援のため）：Google Generative Language API（Gemini）、OpenRouter、OpenAI API、Anthropic API、TypeSafe API、またはこの PC のローカル LLM（Ollama・LM Studio 等） / AI providers (the one the user selects) *optional feature (for decision support): Google Generative Language API (Gemini), OpenRouter, OpenAI API, Anthropic API, TypeSafe API, or Local LLM on this computer (such as Ollama or LM Studio)
  • オープンアクセス検索・書誌サービス ※任意機能（全文 PDF の検索と試験登録情報の取得のため）：NCBI（PubMed Central、E-utilities）、Europe PMC、Unpaywall、OpenAlex、ClinicalTrials.gov、および全文 PDF の配布元のウェブサイト / Open-access search and bibliographic services *optional feature (for finding full-text PDFs and trial registration records): NCBI (PubMed Central, E-utilities), Europe PMC, Unpaywall, OpenAlex, ClinicalTrials.gov, and the websites that host the full-text PDFs
  • 法令に基づく開示要求がある場合 / When required by law

送信したデータは、送信先の各社の規約に従って扱われます。とくに次の点にご注意ください。

Data sent to these services is handled under each provider's own terms. In particular:

  • Gemini API の無料枠では、送信した内容と応答が Google の製品・サービスの提供・改善・開発に使われることがあり、人が読むこともあります。有料の利用ではプロンプトと応答は製品の改善に使われません（Gemini API 追加利用規約）。未公開の原稿や機密の文書を扱うときは、有料の API キーを使うか、AI 判定を使わないでください。 / On the Gemini API free tier, submitted content and responses may be used to provide, improve, and develop Google products and services, and human reviewers may read them. On paid use, prompts and responses are not used to improve Google's products (Gemini API Additional Terms of Service). When handling unpublished manuscripts or confidential documents, use a paid API key or do not use AI screening.
  • OpenRouter は既定では入力と出力をモデルの学習に使いませんが、OpenRouter が中継する先の各プロバイダは独自のデータの扱いを持ちます（OpenRouter のプロバイダのログ記録）。 / OpenRouter does not use inputs or outputs for model training by default, but each provider that OpenRouter routes to has its own data handling policies (OpenRouter provider logging).
  • OpenAI API と Anthropic API は、既定では API で送った内容をモデルの学習に使わないとしています（OpenAI、Anthropic）。 / OpenAI and Anthropic state that, by default, content sent through their APIs is not used to train their models (OpenAI, Anthropic).
  • 各社の規約は変わることがあります。利用前に、ご自身が使うプロバイダの最新の規約と、所属機関の方針を確認してください。 / Provider terms may change. Before use, check the current terms of the provider you use and your institution's policy.

著作権について：フルテキストの AI 判定は、論文の PDF を AI プロバイダへ送信します。出版社の利用条件によっては、閲覧の許諾があっても AI への送信が認められていないことがあります。送信してよいかは、ご自身で出版社の利用条件と所属機関の契約を確認してください。

Copyright: Full-text AI screening sends article PDFs to an AI provider. Some publishers' terms do not permit sending content to AI systems even when you are licensed to read it. Check the publisher's terms and your institution's license before sending a PDF.

6. Google API サービスの利用 / Use of Google API Services

本サービスは Google API サービスを使用しています。本サービスによる Google ユーザーデータの使用は、Google API サービスのユーザーデータポリシー（限定使用要件を含む）に準拠しています。

The Service uses Google API Services. The use of Google user data by this Service complies with the Google API Services User Data Policy, including the Limited Use requirements.

7. データのセキュリティ / Data Security

本サービスは、Google の OAuth 2.0 認証を使用してセキュアな認証を行います。認証トークンは chrome.identity により取得し、Google API の呼び出しに必要な範囲で使用します。

The Service uses Google's OAuth 2.0 authorization. Authentication tokens are obtained via chrome.identity and used only as needed to call Google APIs.

認証トークンはブラウザのセッション内だけに保持し、Chrome終了時に消去されます。次回起動時のサイレント再認証のため、前回使用したGoogleアカウントのメールアドレスのみを端末内に保存し、明示的なログアウト時に削除します。

Authentication tokens are kept only for the browser session and are cleared when Chrome exits. To support silent reauthorization on the next launch, only the email address of the last used Google account is stored on the device and is removed when you explicitly sign out.

本拡張機能は、外部から JavaScript / Wasm をダウンロードして実行することはありません（いわゆるリモートコードは使用しません）。

The extension does not download and execute external JavaScript/Wasm (i.e., we do not use remote code).

AI プロバイダの API キーを保存する場合、ユーザー端末内に暗号化して保存します。

If an AI provider API key is saved, it is stored encrypted on the user's device.

8. ユーザーの権利 / User Rights

ユーザーは以下の権利を有します：

Users have the following rights:

  • アクセス権の取り消し / Revoke Access：: Google アカウント設定から、いつでも本サービスへのアクセス許可を取り消すことができます。 You can revoke access permissions at any time from your Google Account settings.
  • データの削除 / Data Deletion：: Google Drive から該当のスプレッドシートを削除することで、すべてのスクリーニングデータを削除できます。 You can delete all screening data by removing the relevant spreadsheets from your Google Drive.

9. Cookie の使用 / Cookie Usage

本サービスは Cookie を使用しません。設定・オフライン同期用データ等は、Chrome 拡張機能のストレージ API / IndexedDB を使用してユーザー端末内に保存される場合があります。

The Service does not use cookies. Settings and offline sync data may be stored on the user's device using the Chrome extension storage API / IndexedDB.

10. 子どものプライバシー / Children's Privacy

本サービスは13歳未満の子どもを対象としていません。13歳未満のユーザーから意図的に個人情報を収集することはありません。

The Service is not intended for children under 13 years of age. We do not knowingly collect personal information from users under 13.

This Privacy Policy may be updated as needed. If there are significant changes, we will notify you by posting them on this page.
