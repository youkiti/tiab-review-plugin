プライバシーポリシー / Privacy Policy

最終更新日 / Last Updated: 2025年12月27日 / December 27, 2025

1. はじめに / Introduction

TiAb Review Plugin（以下「本サービス」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めています。本プライバシーポリシーは、本サービスが収集する情報とその利用方法について説明します。

TiAb Review Plugin ("the Service") respects user privacy and is committed to protecting personal information. This Privacy Policy explains what information we collect and how we use it.

2. 収集する情報 / Information We Collect

本サービスは、以下の情報にアクセスする許可を要求します：

The Service requests permission to access the following information:

  • Google アカウント情報 / Google Account Information： メールアドレス（ユーザー識別のため） / Email address (for user identification)
  • Google Sheets データ / Google Sheets Data： スクリーニングデータの保存・読み取り / Saving and reading screening data
  • Google Drive ファイル / Google Drive Files： 本サービスで作成したスプレッドシートへのアクセス / Access to spreadsheets created by this Service

3. 情報の利用目的 / How We Use Information

収集した情報は、以下の目的でのみ使用されます：

The information collected is used only for the following purposes:

  • スクリーニングデータの保存・表示 / Saving and displaying screening data
  • ユーザーの識別とアクセス管理 / User identification and access management
  • スプレッドシートの共有機能の提供 / Providing spreadsheet sharing functionality

4. データの保存場所 / Data Storage

重要：本サービスは、ユーザーのデータを開発者のサーバーに送信・保存しません。

Important: The Service does not send or store user data on the developer's servers.

すべてのスクリーニングデータは、ユーザー自身の Google Drive 内の Google Sheets に保存されます。データの管理権限はユーザー自身にあります。

All screening data is stored in Google Sheets within the user's own Google Drive. Users have full control over their data.

5. 情報の第三者提供 / Third-Party Disclosure

本サービスは、ユーザーの個人情報を第三者に販売、貸与、または共有しません。ただし、以下の場合を除きます：

The Service does not sell, rent, or share user personal information with third parties, except in the following cases:

  • ユーザーの明示的な同意がある場合 / With explicit user consent
  • 法令に基づく開示要求がある場合 / When required by law

6. Google API サービスの利用 / Use of Google API Services

本サービスは Google API サービスを使用しています。本サービスによる Google ユーザーデータの使用は、Google API サービスのユーザーデータポリシー（限定使用要件を含む）に準拠しています。

The Service uses Google API Services. The use of Google user data by this Service complies with the Google API Services User Data Policy, including the Limited Use requirements.

7. データのセキュリティ / Data Security

本サービスは、Google の OAuth 2.0 認証を使用してセキュアな認証を行います。アクセストークンはブラウザのローカルストレージに安全に保存され、必要最小限のスコープのみを要求します。

The Service uses Google's OAuth 2.0 authentication for secure authorization. Access tokens are securely stored in the browser's local storage, and only the minimum required scopes are requested.

8. ユーザーの権利 / User Rights

ユーザーは以下の権利を有します：

Users have the following rights:

  • アクセス権の取り消し / Revoke Access： Google アカウント設定から、いつでも本サービスへのアクセス許可を取り消すことができます。 You can revoke access permissions at any time from your Google Account settings.
  • データの削除 / Data Deletion： Google Drive から該当のスプレッドシートを削除することで、すべてのスクリーニングデータを削除できます。 You can delete all screening data by removing the relevant spreadsheets from your Google Drive.

9. Cookie の使用 / Cookie Usage

本サービスは Cookie を使用しません。認証情報は Chrome 拡張機能の標準ストレージ API を使用して保存されます。

The Service does not use cookies. Authentication information is stored using the Chrome extension's standard storage API.

10. 子どものプライバシー / Children's Privacy

本サービスは13歳未満の子どもを対象としていません。13歳未満のユーザーから意図的に個人情報を収集することはありません。

The Service is not intended for children under 13 years of age. We do not knowingly collect personal information from users under 13.

11. プライバシーポリシーの変更 / Changes to This Policy

本プライバシーポリシーは、必要に応じて更新されることがあります。重要な変更がある場合は、本ページに掲載することでお知らせします。

This Privacy Policy may be updated as needed. If there are significant changes, we will notify you by posting them on this page.

12. お問い合わせ / Contact Us

本プライバシーポリシーに関するご質問やご懸念がある場合は、GitHub Issue にてお問い合わせください。

If you have any questions or concerns about this Privacy Policy, please contact us via GitHub Issue.
