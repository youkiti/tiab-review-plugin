🔬 TiAb Review Plugin

プライバシーポリシー / Privacy Policy

最終更新日: 2026年7月16日 / Last Updated: July 16, 2026

1. はじめに / Introduction

TiAb Review Plugin（以下「本サービス」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めています。本プライバシーポリシーは、本サービスが収集する情報とその利用方法について説明します。

TiAb Review Plugin ("the Service") respects user privacy and is committed to protecting personal information. This Privacy Policy explains what information we collect and how we use it.

2. 収集する情報 / Information We Collect

本サービスは、以下の情報にアクセスする許可を要求します：

The Service requests permission to access the following information:

  • Google アカウント情報 / Google Account Information：: メールアドレス（ユーザー識別のため） / Email address (for user identification)
  • Google Sheets データ / Google Sheets Data：: ユーザーが本サービスに接続したスプレッドシート（本サービス内で新規作成したもの、およびユーザーが Google ピッカーで明示的に選択したもの）に対する、スクリーニングデータの読み取り・書き込み / Reading and writing screening data in spreadsheets that the user connects to the Service — including spreadsheets newly created within the Service and spreadsheets explicitly selected by the user with Google Picker
  • Google Drive ファイル / Google Drive Files：: 本サービスがユーザーの Google Drive 内に作成したファイル・フォルダ（プロジェクト用フォルダ、取得した全文PDF等）へのアクセス / Access to files and folders that the Service creates in the user's Google Drive (e.g., project folders and retrieved full-text PDFs)
  • LLM（Gemini）機能（任意） / LLM (Gemini) Feature (Optional)：: ユーザーが明示的に実行した場合に、文献のタイトル・抄録などを Gemini API に送信し、判定支援を行います。 / When explicitly enabled by the user, the Service sends reference titles, abstracts, etc. to the Gemini API to assist screening.
  • 拡張機能のローカル保存データ / Extension Local Storage：: 設定（スプレッドシートID、UI設定等）、オフライン同期用の判定キュー、（任意）Gemini APIキーをユーザー端末内に保存します。 / We store settings (spreadsheet ID, UI preferences, etc.), an offline decision queue for synchronization, and (optionally) the Gemini API key on the user's device.

3. 情報の利用目的 / How We Use Information

収集した情報は、以下の目的でのみ使用されます：

The information collected is used only for the following purposes:

  • スクリーニングデータの保存・表示 / Saving and displaying screening data
  • ユーザーの識別とアクセス管理 / User identification and access management
  • スプレッドシートの共有機能の提供 / Providing spreadsheet sharing functionality
  • （任意）LLM（Gemini）による判定支援 / (Optional) Decision support via LLM (Gemini)

4. データの保存場所 / Data Storage

重要：本サービスは、ユーザーのデータを開発者のサーバーに送信・保存しません。

Important: The Service does not send or store user data on the developer's servers.

すべてのスクリーニングデータは、ユーザー自身の Google Drive 内の Google Sheets に保存されます。データの管理権限はユーザー自身にあります。

All screening data is stored in Google Sheets within the user's own Google Drive. Users have full control over their data.

また、本拡張機能の設定やオフライン同期用の判定キューは、ユーザー端末内（Chrome 拡張機能のストレージ / IndexedDB）に保存される場合があります。

In addition, the extension's settings and offline decision queue may be stored on the user's device (Chrome extension storage / IndexedDB).

Gemini APIキーは、ユーザーが「保存」を選択した場合に限り、ユーザー端末内に保存されます（開発者のサーバーには送信・保存しません）。

The Gemini API key is stored only on the user's device if the user chooses to save it (we do not send or store it on developer servers).

5. 情報の第三者提供 / Third-Party Disclosure

本サービスは、ユーザーの個人情報を第三者に販売、貸与、または不必要に共有しません。

The Service does not sell, rent, or unnecessarily share user personal information with third parties.

ただし、本サービスの提供に必要な範囲で、ユーザーの操作に応じて以下の第三者サービスへデータを送信する場合があります：

However, to provide the Service, we may send data to the following third-party services based on user actions:

  • Google Sheets API / Google Drive API / Google Picker API（スプレッドシートの読み書き、作成・選択のため） / Google Sheets API / Google Drive API / Google Picker API (to read/write, create, and select spreadsheets)
  • Google Generative Language API（Gemini）※任意機能（判定支援のため） / Google Generative Language API (Gemini) *optional feature (for decision support)
  • 法令に基づく開示要求がある場合 / When required by law

6. Google API サービスの利用 / Use of Google API Services

本サービスは Google API サービスを使用しています。本サービスによる Google ユーザーデータの使用は、Google API サービスのユーザーデータポリシー（限定使用要件を含む）に準拠しています。

The Service uses Google API Services. The use of Google user data by this Service complies with the Google API Services User Data Policy, including the Limited Use requirements.

7. データのセキュリティ / Data Security

本サービスは、Google の OAuth 2.0 認証を使用してセキュアな認証を行います。認証トークンは chrome.identity により取得し、Google API の呼び出しに必要な範囲で使用します。

The Service uses Google's OAuth 2.0 authorization. Authentication tokens are obtained via chrome.identity and used only as needed to call Google APIs.

認証トークンはブラウザのセッション内だけに保持し、Chrome終了時に消去されます。次回起動時のサイレント再認証のため、前回使用したGoogleアカウントのメールアドレスのみを端末内に保存し、明示的なログアウト時に削除します。

Authentication tokens are kept only for the browser session and are cleared when Chrome exits. To support silent reauthorization on the next launch, only the email address of the last used Google account is stored on the device and is removed when you explicitly sign out.

本拡張機能は、外部から JavaScript / Wasm をダウンロードして実行することはありません（いわゆるリモートコードは使用しません）。

The extension does not download and execute external JavaScript/Wasm (i.e., we do not use remote code).

Gemini APIキーを保存する場合、ユーザー端末内に暗号化して保存します。

If the Gemini API key is saved, it is stored encrypted on the user's device.

8. ユーザーの権利 / User Rights

ユーザーは以下の権利を有します：

Users have the following rights:

  • アクセス権の取り消し / Revoke Access：: Google アカウント設定から、いつでも本サービスへのアクセス許可を取り消すことができます。 You can revoke access permissions at any time from your Google Account settings.
  • データの削除 / Data Deletion：: Google Drive から該当のスプレッドシートを削除することで、すべてのスクリーニングデータを削除できます。 You can delete all screening data by removing the relevant spreadsheets from your Google Drive.

9. Cookie の使用 / Cookie Usage

本サービスは Cookie を使用しません。設定・オフライン同期用データ等は、Chrome 拡張機能のストレージ API / IndexedDB を使用してユーザー端末内に保存される場合があります。

The Service does not use cookies. Settings and offline sync data may be stored on the user's device using the Chrome extension storage API / IndexedDB.

10. 子どものプライバシー / Children's Privacy

本サービスは13歳未満の子どもを対象としていません。13歳未満のユーザーから意図的に個人情報を収集することはありません。

The Service is not intended for children under 13 years of age. We do not knowingly collect personal information from users under 13.

11. プライバシーポリシーの変更 / Changes to This Policy

本プライバシーポリシーは、必要に応じて更新されることがあります。重要な変更がある場合は、本ページに掲載することでお知らせします。

This Privacy Policy may be updated as needed. If there are significant changes, we will notify you by posting them on this page.

本プライバシーポリシーに関するご質問やご懸念がある場合は、GitHub Issue にてお問い合わせください。

If you have any questions or concerns about this Privacy Policy, please contact us via GitHub Issue.
